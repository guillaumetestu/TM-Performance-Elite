# TM Performance Elite

Site premium destiné aux footballeurs professionnels évoluant dans le top 5 des grands championnats européens.

## Structure

- `index.html` — Page d'accueil (hero, mission, expertise, méthode, citations)
- `methodologie.html` — La méthodologie en quatre temps
- `services.html` — Les huit domaines d'expertise + trois formats d'accompagnement
- `contact.html` — Formulaire d'entretien confidentiel
- `assets/style.css` — Système de design partagé
- `assets/script.js` — Interactions communes

## Aesthetic

- Palette : noir profond, accents or et bordeaux
- Typographie : Cormorant Garamond (serif éditorial), Inter (sans), JetBrains Mono (caps)
- Direction : éditorial luxe, magazine de haute performance
- Animations : reveals subtils au scroll, citations rotatives en homepage

## Déploiement GitHub Pages

1. Créer un repo nommé `TM-Performance-Elite` (ou autre)
2. Pousser tous les fichiers à la racine
3. Settings → Pages → Source: `main` branch, `/` (root)
4. URL publiée : `https://[username].github.io/TM-Performance-Elite/`

## Custom domain (optionnel)

Pour utiliser un domaine type `elite.tm-performance.com` :
- Ajouter un fichier `CNAME` à la racine contenant le domaine
- Configurer le DNS chez le registrar (CNAME → `[username].github.io`)

## Maintenance

Les modifications de texte se font directement sur les fichiers HTML.
Pour modifier la palette : `assets/style.css`, section `:root` en haut.
